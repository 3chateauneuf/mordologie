Algoritmo inicial

Como decide

  1. Busca referencias del mismo periodo del ano pasado.
  2. Mira semanas recientes con un patron parecido.
  3. Si hay poco historial, se apoya en los ultimos 3 meses.
  4. Convierte eso en una ventana sugerida y un limite blando.
Interpretacion actual de tu idea

Para `Levothyrox`, la recomendacion no fija una hora dura. Usa tu historial para proponer una hora ancla y deja un margen. El limite blando se empuja un poco mas tarde segun tus registros tardios recientes.

Lectura del cronometro de desarrollo

`Tiempo total` cuenta toda la sesion abierta. `Actividad tuya estimada` sube cuando interactuas con la pagina. `Espera o sistema` es la diferencia: sirve como aproximacion del tiempo en que el proyecto sigue abierto pero no estas actuando directamente, incluyendo lectura, reflexion y espera del sistema.
